ABOUT DETECT NOW

Supporting safer use of digital media.

Detect Now is an academic deepfake-detection prototype developed by Group 20 at Charles Darwin University.

OUR PROJECT

Why we developed Detect Now

Deepfake technology can create or modify digital media so that manipulated content appears realistic. This makes it difficult for normal users to determine whether an image or video is genuine.

Our project focuses on developing a simple tool that can support users when checking suspicious digital media. The current prototype uses an EfficientNetB0 model trained and fine-tuned using real and manipulated facial frames.

01

Our Aim

To develop a practical and user-friendly tool that can help identify possible deepfake content using deep learning.

02

Our Approach

We combine a web interface, image preprocessing, human-face validation and a trained EfficientNetB0 classification model.

03

Our Direction

We are beginning with facial-image detection. Video frame extraction and video detection will be added during the next development stage.

TECHNOLOGY

How the current prototype works

When a user uploads an image, YuNet locates a visible human face. The backend crops around that face, pads the crop to a square and resizes it to 224 by 224 pixels.

The trained EfficientNetB0 classifier processes the face crop and returns a verdict of likely real, uncertain or likely deepfake. The interface shows its deepfake score and the verdict bands (below 15% likely real, 15% to under 50% uncertain, 50% and above likely deepfake). Scores are not calibrated probabilities.

DATASET AND TRAINING

How we developed the model

The current face swap classifier (v2) was built in two stages. The original model was fine-tuned on cropped real and face-swapped portraits from a Kaggle dataset, with YuNet used to prepare 14,090 training faces and 1,939 validation faces. It was then fine-tuned again on 2,748 face crops (about 1,400 Kaggle frames plus 1,354 images made with the inswapper tool), with 602 crops for validation, using flip, JPEG-compression, brightness and contrast augmentation.

The model uses EfficientNetB0 for image classification. Face detection and classification are separate steps.

Results for other types of AI image edits need separate evaluation. A face swap result does not establish performance on every kind of manipulated image.

MODEL DEVELOPMENT

EfficientNetB0 transfer learning

We started with EfficientNetB0 using ImageNet weights. During the first training stage, the EfficientNetB0 base was frozen and only the classification layer was trained.

During the second stage, the final EfficientNetB0 layers were unfrozen and fine-tuned using a smaller learning rate. Model checkpoints, early stopping and learning-rate reduction were used during training.

IMPORTANT LIMITATIONS

The result is guidance, not proof

The internal face swap check does not measure performance on new datasets. Portrait edits outside that dataset were missed during our separate development check.

Image quality, compression, lighting, face position and unfamiliar manipulation methods may affect results. The deepfake score is not a calibrated probability.

Detect Now is an academic prototype and should not be the only evidence for an important decision.

RUN THE PROTOTYPE

How to run Detect Now

These steps run the image detection prototype locally on Windows. Use the project folder containing backend.py, requirements.txt, index.html and static/app.js.

1. Check the model files. The model folder must contain:

  • detect_now_efficientnetb0_faceswap_crops_v2.keras
  • decision_threshold_detect_now_efficientnetb0_faceswap_crops_v2.json
  • face_detection_yunet_2023mar.onnx

2. Open the project folder in VS Code. In its terminal, create a Python environment and install the dependencies:

py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

3. Start the backend in that terminal:

.\.venv\Scripts\python.exe backend.py

Keep it running at http://127.0.0.1:5000.

4. Start the website in a second terminal opened in the same project folder:

.\.venv\Scripts\python.exe -m http.server 5500 --bind 127.0.0.1

Open http://127.0.0.1:5500 in a browser. Select an image containing a visible human face and choose Analyse.

The result is an experimental model prediction. Face swap results do not establish accuracy for other forms of image editing.
