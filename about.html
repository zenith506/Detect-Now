ABOUT DETECT NOW

Supporting safer use of digital media.

Detect Now is an academic deepfake-detection prototype developed by Group 20 at Charles Darwin University.

OUR PROJECT

Why we developed Detect Now

Deepfake technology can create or modify digital media so that manipulated content appears realistic. This makes it difficult for normal users to determine whether an image or video is genuine.

Our project focuses on developing a simple tool that can support users when checking suspicious digital media. The current prototype uses an EfficientNetB0 model trained and fine-tuned using real and manipulated facial frames.

01

Our Aim

To develop a practical and user-friendly tool that can help identify possible deepfake content using deep learning.

02

Our Approach

We combine a web interface, image preprocessing, human-face validation and a trained EfficientNetB0 classification model.

03

Our Direction

We are beginning with facial-image detection. Video frame extraction and video detection will be added during the next development stage.

TECHNOLOGY

How the current prototype works

When a user uploads an image, Detect Now checks whether it contains a visible human face. The full image is then resized to 224 by 224 pixels and prepared for the detection model.

Our trained EfficientNetB0 model processes the image and returns a binary prediction: Real or Deepfake. The interface also displays the confidence score and the probability for each category.

DATASET AND TRAINING

How we developed the model

We used the publicly available DFDC Part 34 dataset. The original dataset contained 416 real videos and 2,242 fake videos. To reduce class imbalance, we selected one matching fake video for each real video.

This produced 416 real and 416 fake video groups. Ten frames from each selected video were used where available. The final prepared dataset contained 5,820 training images, 1,240 validation images and 1,260 testing images.

The video groups were separated before creating the image lists. This helped prevent frames from the same video pair appearing in both training and testing data.

MODEL PERFORMANCE

Testing results

MODEL DEVELOPMENT

EfficientNetB0 transfer learning

We started with EfficientNetB0 using ImageNet weights. During the first training stage, the EfficientNetB0 base was frozen and only the classification layer was trained.

During the second stage, the final EfficientNetB0 layers were unfrozen and fine-tuned using a smaller learning rate. Model checkpoints, early stopping and learning-rate reduction were used during training.

IMPORTANT LIMITATIONS

The result is guidance, not proof

The model achieved 76.67% accuracy on our testing dataset, which means it can still produce incorrect results. Performance may be affected by image quality, lighting, compression, face position and manipulation methods that were not included in the training dataset.

The DFDC dataset mainly contains facial manipulations taken from videos. Fully AI-generated images or new manipulation methods may be more difficult for the model to classify correctly.

Detect Now is an academic prototype and should not be used as the only evidence when making important decisions.
