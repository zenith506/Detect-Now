ABOUT DETECT NOW

Supporting safer use of digital media.

Detect Now is an academic deepfake-detection prototype developed by Group 20 at Charles Darwin University.

OUR PROJECT

Why we developed Detect Now

Deepfake technology can create or modify digital media so that fake content appears realistic. This can make it difficult for normal users to identify whether an image or video is genuine.

Our project focuses on developing a simple tool that can support users when checking suspicious digital media. The current prototype uses a pretrained deep-learning model to analyse facial images.

01

Our Aim

To develop a practical and user-friendly tool that can help identify possible deepfake content.

02

Our Approach

We combine a simple web interface, face detection and a pretrained image-classification model.

03

Our Direction

We are beginning with facial-image detection and plan to add video detection in a later stage.

TECHNOLOGY

How the current prototype works

When a user uploads an image, Detect Now first checks whether the file contains a clear human face. If a face is detected, the image is prepared and sent to a pretrained model.

The model returns a prediction showing whether the face is likely real, likely deepfake or uncertain. It also provides confidence and probability values.

IMPORTANT LIMITATIONS

The result is guidance, not proof

Deepfake detection is difficult and no model is completely accurate. Results may be affected by image quality, lighting, compression, face position and manipulation methods that were not included in the model's training data.

Detect Now is an academic prototype and should not be used as the only evidence when making important decisions.
